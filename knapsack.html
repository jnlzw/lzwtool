先看三句话

背包问题的 DP 都是同一件事：逐个考虑物品，逐步更新 dp 数组。要抓的只有三点：

  • 状态：dp[j] = 容量 j 的背包能达到的某种指标（最大价值 / 是否可行 / 方案数）
  • 转移：从 dp[j - w] 推导 dp[j]（选这件 or 不选）
  • 顺序：0/1 倒序、完全正序；组合外物品内容量、排列外容量内物品

下面 4 个动画，每个都只演示一条 dp 数组的更新过程。点「播放」看它自己走，或用「下一步」慢慢品。

① 0/1 背包 —— 一切的根基 P10

题目：有 n 件物品和一个容量为 capacity 的背包，第 i 件物品重 weights[i]、价值 values[i]，每件最多选一次，求不超过容量时的最大价值。
示例：输入 weights=[2,3,4,5], values=[3,4,5,6], capacity=5 → 输出 7（选物品0+物品1：重 5，值 3+4）。

dp[j] = max(dp[j], dp[j - w[i]] + v[i])。
一维数组必须从右往左更新：右边先改，左边的 dp[j-w] 还是"没选过当前物品"的旧值，保证每件物品只用一次。正序就漏了——看下一个动画对比。 
for (int i = 0; i < n; i++)
    for (int j = C; j >= w[i]; j--)   // 倒序！
        dp[j] = max(dp[j], dp[j - w[i]] + v[i]);

② 分割等和子集 —— 0/1 的"可行性"变体 P13 · LeetCode 416

题目（LC 416）：给你一个只含正整数的非空数组 nums，判断能否把它 分割成两个子集，使两个子集的元素和相等。
示例：输入 nums=[1,5,11,5] → 输出 true （[1,5,5] 与 [11]）。提示：总和 22，问题等价于"能否凑出 11"。

数字既是重量也是价值，背包容量 = sum/2。
dp[j] = dp[j] || dp[j - num]：boolean 数组，转移用"或"。 最后只看 dp[11] 一格。 
for (int num : nums)
    for (int j = target; j >= num; j--)
        dp[j] = dp[j] || dp[j - num];

③ 零钱兑换 II —— 完全背包"组合数" P16 · LeetCode 518

题目（LC 518）：给你整数数组 coins 表示不同面额硬币、整数 amount 表示总金额，每种硬币有无限个。返回凑成总金额的硬币组合数 （凑不出返回 0）。
示例：输入 amount=5, coins=[1,2,5] → 输出 4 （5 / 2+2+1 / 2+1+1+1 / 1×5）。

无限件 → 正序遍历：左边先改，dp[j-coin] 可能已含当前硬币，正好允许重复选。
外层硬币、内层容量保证硬币按顺序加入：{1,2} 和 {2,1} 只算一种 → 组合数。 
dp[0] = 1;
for (int coin : coins)                        // 外物品
    for (int j = coin; j <= amount; j++)      // 内容量，正序
        dp[j] += dp[j - coin];

④ 组合总和 IV —— 完全背包"排列数" P17 · LeetCode 377

题目（LC 377）：给你由不同整数组成的数组 nums 和目标整数 target，元素可重复用。返回总和为 target 的组合个数——注意顺序不同 算不同方案（实为排列）。
示例：输入 nums=[1,2,3], target=4 → 输出 7 （1111 / 112 / 121 / 211 / 22 / 13 / 31）。

与 518 题面几乎一样，唯一差别是"顺序不同算不同"。
解法上体现为内外循环颠倒：外层容量、内层物品。对每个容量 j， 任何物品都可能排在最后一位 → 排列数。 
dp[0] = 1;
for (int j = 1; j <= target; j++)           // 外容量
    for (int num : nums)                      // 内物品
        if (j >= num) dp[j] += dp[j - num];

⑤ 一和零 —— 二维费用 0/1 背包 P19 · LeetCode 474

题目（LC 474）：给你二进制字符串数组 strs 和两个整数 m、n。 返回 strs 的最大子集的大小，要求子集中 '0' 不超过 m 个、'1' 不超过 n 个。
示例：输入 strs=["10","0001","111001","1","0"], m=5, n=3 → 输出 4（子集 {"10","0001","1","0"}：共 5 个 0、3 个 1； "111001" 有 4 个 1 装不下）。

普通背包只有一种"费用"（重量）；这题每个字符串同时消耗两种费用： 0 的个数和 1 的个数。所以 dp 表是二维的：
dp[i][j] = max(dp[i][j], dp[i-z][j-o] + 1)， z/o 是当前串的 0/1 个数。
仍然是 0/1 背包 → 两个维度都倒序。动画里蓝格是 dp[i][j]， 黄格是它读取的左上方向 dp[i−z][j−o]。 
for (String s : strs) { int z = cnt(s,'0'), o = cnt(s,'1');
    for (int i = m; i >= z; i--)          // 两个维度都倒序
        for (int j = n; j >= o; j--)
            dp[i][j] = max(dp[i][j], dp[i-z][j-o] + 1); }

⑥ 盈利计划 —— "至少" 是道坎 P22 · LeetCode 879 · 困难

题目（LC 879）：有 n 名员工。第 i 种工作需要 group[i] 人参与、 产生 profit[i] 利润，每种工作最多做一次，同一人不能同时做两项。 返回总利润至少为 minProfit 的计划数（参与总人数 ≤ n）， 对 10⁹+7 取模。
示例：输入 n=5, minProfit=3, group=[2,2], profit=[2,3] → 输出 2（只做工作1 {利润3}，或两件都做 {利润5}； 只做工作0 利润 2 不达标）。

二维费用（人数 + 利润）+ 方案数，但真正的坑是"至少 minProfit"： 利润超出的方案不能按真实利润分开存，否则同一个方案会被重复计数。
技巧叫钳位：dp 第三维只开到 minProfit，转移时 dp[i][j] += dp[i−g][max(0, j−p)]——超额利润统统压到 j = minProfit 那一格。答案也不是一格，是 j=minProfit 整列之和（人数 ≤ n 都行）。 
for (int k = 0; k < group.length; k++) { int g = group[k], p = profit[k];
    for (int i = n; i >= g; i--)
        for (int j = minProfit; j >= 0; j--)
            dp[i][j] += dp[i-g][max(0, j-p)]; }   // j 也倒序，二维都是 0/1

⑦ 最高的广告牌 —— 状态本身就是答案的一半 P23 · LeetCode 956 · 困难

题目（LC 956）：安装一个广告牌需要两个等长的钢架。 给你一堆钢筋 rods，每根可以焊到任意一边或不使用。返回广告牌的最大 可能高度（公共长度），无法安装返回 0。
示例：输入 rods=[1,2,3,6] → 输出 6 （一边 {6}，另一边 {1,2,3}）。

背包 dp 不一定索引"容量"。这题的状态是差值： dp[d] = 两边差为 d 时，较长边的最大长度。
每根杆有三种选择：不放 / 放高边 / 放矮边——一次读取要往两个格子写， 就地更新会拿新值算旧值，所以必须整行快照（clone 上一步）。 不是所有背包都能滚动数组原地改！ 
int[] cp = dp.clone();                      // 快照：读旧写新
for (int d = 0; d <= sum; d++) {
    ndp[d + r] = max(ndp[d + r], cp[d] + r);              // 放高边
    ndp[abs(d - r)] = max(ndp[abs(d-r)], cp[d] + max(r-d, 0)); // 放矮边
}

⑧ 给墙壁刷油漆 —— 最难的一步在 DP 之前 P24 · LeetCode 2742 · 困难

题目（LC 2742）：两个等长数组 cost 和 time：付费工人刷第 i 面墙 收费 cost[i]、耗时 time[i]；另有一名免费工人，在付费工人干活的每个 单位时间能免费刷一面墙（不重复刷已刷的）。返回刷完全部 n 面墙的 最少花费。
示例：输入 cost=[1,2,3,2], time=[1,2,3,2] → 输出 3 （付费刷墙0 花1元耗时1→免费刷1面，付费刷墙3 花2元耗时2→免费刷2面， 共 2+3=5 ≥ 4 面，花 1+2=3）。

建模转换：付费刷第 i 面墙的 time[i] 期间，免费工人顺手刷掉 time[i] 面 → 付费一面等价于"覆盖 time[i]+1 面墙"。
于是一个 0/1 背包出现了：容量 = 墙数 n，费用 = cost， 求盖满 n 的最小花费——注意是 min 模式、不可达用 ∞， 且读取端要钳到 0：dp[j] = min(dp[j], dp[max(0, j−w)] + cost)。 
for (int i = 0; i < n; i++) { int w = time[i] + 1;
    for (int j = n; j >= 0; j--)
        dp[j] = min(dp[j], dp[max(0, j - w)] + cost[i]); }

⑨ 单词拆分 —— 穿着字符串外衣的完全背包 P25 · LeetCode 139

题目（LC 139）：给你字符串 s 和字符串列表 wordDict 作为字典， 判断 s 能否由字典中的单词拼接而成。单词可以重复使用， 不必全部用上。
示例：输入 s="leetcode", wordDict=["leet","code"] → 输出 true（"leet"+"code"）。反例：s="catsandog", dict=["cats","dog","sand","and","cat"] → false。

把字符串当背包、单词当物品：dp[j] = s 前 j 个字符能否拼出， dp[j] = dp[j] || (dp[j-len] && s[j-len..j]==word)。
单词无限供应 → 完全背包；拼接有顺序 → 外容量内物品 （和 ④ 组合总和 IV 一模一样的循环结构）。
认出这一层，这题就不用重新发明轮子了。 
dp[0] = true;
for (int j = 1; j <= s.length(); j++)      // 外容量
    for (String w : dict)                    // 内物品
        if (j >= w.length() && s.startsWith(w, j - w.length()))
            dp[j] = dp[j] || dp[j - w.length()];

⑩ 预测赢家 —— 转移可以一次读两个格 P26 · LeetCode 486

题目（LC 486）：给你整数数组 nums，玩家1和玩家2轮流从数组的 某一端取走一个数，取走后移除，玩家1先手。双方都采取最优策略， 玩家1 最终得分 ≥ 玩家2 则返回 true。
示例：输入 nums=[1,5,2] → 输出 false （先手只能拿端点 1 或 2，无论拿哪个，5 都被对手拿走）。 示例2：nums=[1,5,233,7] → true。

区间 DP + 博弈：dp[i][j] = 区间 [i,j] 上先手净胜的最大分差。
dp[i][j] = max(nums[i] − dp[i+1][j], nums[j] − dp[i][j−1])
拿完左边，对手在 [i+1,j] 上变先手——你的净胜 = 拿的 − 对手净胜， 负负得正正是博弈 DP 的味道。按区间长度填表， 动画里一格同时读下方和左方两个格。 
for (int len = 1; len <= n; len++)
    for (int i = 0; i + len - 1 < n; i++) { int j = i + len - 1;
        dp[i][j] = len == 1 ? nums[i]
            : max(nums[i] - dp[i+1][j], nums[j] - dp[i][j-1]); }

⑪ 打家劫舍 III —— 真正的"树上背包" P27 · LeetCode 337

题目（LC 337）：每间房子是二叉树的一个节点，直接相连的 父子节点不能同一天打劫（触发警报）。求一晚能盗取的最大金额。
示例：输入 root=[3,2,3,null,3,null,1]（下方动画里那棵树）→ 输出 7（偷根 3 + 两个叶子 3+1，祖孙不相邻）。 示例2：root=[3,4,5,1,3,null,1] → 9。

背包里"选/不选"受容量约束；树上受父子邻接约束。 每个节点算两个状态后序上交：
rob = val + 左skip + 右skip（选了，孩子必不选）
skip = max(左rob,左skip) + max(右rob,右skip)（不选，孩子随意）
动画里黄节点是被读取的子节点，蓝节点正在写入它的 (选, 不选)。 
int[] dfs(node) {                       // 返回 {rob, skip}
    if (node == null) return {0, 0};
    int[] l = dfs(node.left), r = dfs(node.right);
    return { node.val + l[1] + r[1],
             max(l[0], l[1]) + max(r[0], r[1]) };
}
